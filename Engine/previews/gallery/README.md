# Gallery

Captures worth keeping: real frames from real projects, kept for the website, the
README, release notes, and store pages.

These are not test fixtures. Nothing reads them, no golden harness compares
against them, and deleting one breaks nothing. They are here so a good frame does
not sit in a Screenshots folder until it is lost.

Name a file for what it shows, not when it was taken.

| File | What it shows |
|---|---|
| `sailing-halftone-dither.png` | Halftone and dither post-processing over a sailing sim. Sepia sky against cyan water, ordered-dot screen door across the whole frame, wireframe swell under the surface, and a full sailing HUD (points of sail, wind, tide, heel, lap). |

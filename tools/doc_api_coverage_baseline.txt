# How many registered script bindings are NOT named in docs/SCRIPTING_API.md.
#
# Was 629 when first measured (2026-09-16): the reference was hand-written and
# named barely half of what the engine registered. tools/gen_scripting_api.py now
# generates a complete signature index into that document, which took it to 10.
#
# The 10 that remain are object PROPERTY accessors -- get_position, set_rotation
# and their siblings -- registered on the Transform/entity type rather than as
# global functions, so a global-binding index correctly leaves them out. They are
# covered by the hand-written prose instead.
#
# This number is a CEILING. `check_doc_api.py --strict` fails when it rises,
# which now catches a new binding registered without regenerating the index.
10

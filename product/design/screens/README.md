# Screens

One file per screen. Start from `../ux-kit/TEMPLATE-screen.svg` (Save As, never
edit it in place) and paste parts from `../ux-kit/STENCIL.svg`.

Name files after what the person is doing, not after the panel:
`build-for-web.svg`, not `build-dialog.svg`.

Set the status in the title block as you go: `exploring`, `settled`, `built`.
A screen marked `settled` is a spec, and the implementation follows it rather
than a description of it.

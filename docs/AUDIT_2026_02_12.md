# Part 1: Security (22 findings)

## CRITICAL

### N1. Command Injection in Shader Compiler via `std::system()`
**File:** `Engine/src/Renderer/Vulkan/VulkanShader.cpp:107,116`
**Description:** `ShaderCompiler::CompileGLSL()` constructs a shell command by string-concatenating file paths into `std::system()`. Previous audit (S34-S36) fixed EditorLayer and HotReload but missed this instance.
**Fix:** Replace `std::system()` with `CreateProcessA()` on Windows / `fork()+exec()` on Unix.

### N2. Command Injection in Git Integration via `popen()`
**File:** `Engine/src/Editor/EditorLayer.cpp:25688-25692`
**Description:** `RunGitCommand()` passes user-controlled `args` and `workingDir` strings directly into `_popen()` via shell command construction. The `workingDir` comes from the project path which could contain shell metacharacters.
**Fix:** Replace `popen()` with `CreateProcessA()` / `posix_spawn()`.

### N3. Command Injection in macOS/Linux File Dialogs via `popen()`
**File:** `Engine/src/Platform/FileDialog.cpp:184,202-234,243-255`
**Description:** On macOS and Linux, file dialog functions construct `osascript` / `zenity` / `kdialog` commands by directly interpolating user-provided strings (title, defaultPath, defaultName, filter extensions) into shell commands passed to `popen()`.
**Fix:** Use native APIs (`NSOpenPanel`/`NSSavePanel` on macOS, `execvp()` on Linux).

### N4. NaN/Infinity Injection via Network Entity Snapshots
**File:** `Engine/src/Networking/NetworkSystem.cpp:631-669`
**Description:** `HandleEntitySnapshot()` reads `f32` values from network packets and directly writes to `TransformComponent` fields with no finiteness validation. NaN/Inf propagates through rendering pipeline.
**Fix:** Validate all float components with `std::isfinite()`. Discard snapshot if any value is NaN/Inf.

## HIGH

### N5. XSS in HTML5 Export via Unescaped Config Fields
**File:** `Engine/src/Build/HTML5Exporter.cpp:106,109,122,168`
**Description:** `GenerateHTML()` interpolates `config.title`, `config.customCSS`, `config.backgroundColor` into HTML without escaping. A project title containing `<script>` executes in browser.
**Fix:** HTML-encode title, validate backgroundColor as CSS color, sanitize customCSS.

### N6. PlayerId Overflow Wraps to Host ID
**File:** `Engine/src/Networking/NetworkSystem.cpp:484`
**Description:** `PlayerId` is `u8`. After 255 cumulative connections, `m_NextPlayerId++` wraps to 0 (host's ID), enabling ownership spoofing.
**Fix:** Check before increment, reject connection if wrap would occur, or recycle disconnected IDs.

### N7. Lobby Player Count Truncation to u8
**File:** `Engine/src/Networking/NetworkSystem.cpp:1118`
**Description:** `m_LobbyPlayers.size()` cast to `u8` — if it exceeds 255, count truncates and remaining bytes are misinterpreted.
**Fix:** Cap to `min(size, 255)` or use `WriteU16`.

### N8. Missing `payloadSize` Validation in Packet Handling
**File:** `Engine/src/Networking/NetworkSystem.cpp:378-412`
**Description:** `HandlePacket()` reads `payloadSize` from header but never validates against actual remaining bytes. Truncated packets produce silent data corruption.
**Fix:** Verify `payloadSize == size - offset`, drop packet if mismatch.

### N9. RPC Data Size Mismatch — Remote Buffer Over-read
**File:** `Engine/src/Networking/NetworkSystem.cpp:786-810`
**Description:** RPC `dataSize` is silently clamped if larger than remaining bytes. Callback receives truncated data without knowing.
**Fix:** Drop the RPC entirely if `dataSize > size - offset`.

### N10. RPC Hash Collision Enables Shadowing
**File:** `Engine/include/Enjin/Networking/NetworkTypes.h:290-297`
**Description:** RPCs stored/dispatched by 32-bit FNV-1a hash. A client can register a collision hash to shadow a privileged RPC.
**Fix:** Transmit and verify full RPC name string, or maintain a server-side whitelist.

## MEDIUM

### N11. Remaining `std::system()` on Linux/macOS
**File:** `Engine/src/Editor/EditorLayer.cpp:11891,18542,21614,21617`
**Description:** Previous audit fixed Windows paths but `#else` branches still use `std::system()` for git init, IDE opening, folder opening.
**Fix:** Replace with `posix_spawn()` or `fork()+execvp()`.

### N12. Newgrounds API JSON Injection via `period` Parameter
**File:** `Engine/src/Networking/NewgroundsAPI.cpp:163`
**Description:** `period` parameter interpolated into JSON without escaping. A period containing `"` breaks out of the JSON string.
**Fix:** Validate `period` against known values ("D", "W", "M", "Y", "A").

### N13. Save File JSON Missing `contains()` for Nested Fields
**File:** `Engine/src/Scene/GameSaveSystem.cpp:161-201`
**Description:** Save file array entries accessed with `entry["name"]` and `entry["value"]` without `contains()` checks. Malformed save throws uncaught `out_of_range`.
**Fix:** Add `.contains()` checks or wrap in `try/catch (nlohmann::json::exception&)`.

### N14. HTTP Response Body Unbounded Allocation
**File:** `Engine/src/Networking/HTTPClient.cpp:160-171`
**Description:** Response body accumulated in `std::string` without size limit. Malicious server causes OOM.
**Fix:** Cap at 16 MB, break on limit exceeded.

### N15. Newgrounds `ExtractInt` Uncaught `std::stoi` Exception
**File:** `Engine/src/Networking/NewgroundsAPI.cpp:312`
**Description:** `std::stoi()` throws `out_of_range` on overflow, uncaught.
**Fix:** Use `std::strtol` with range checking.

### N16. Level Streaming Path Traversal
**File:** `Engine/src/Scene/LevelStreaming.cpp:197-203`
**Description:** `chunk.scenePath` from deserialized JSON passed directly to `LoadAdditive()` without path validation.
**Fix:** Validate path stays within project directory.

### N17. CRC32 Table Initialization Race Condition
**File:** `Engine/src/Build/AssetPacker.cpp:10-23`
**Description:** `InitCRC32Table()` uses non-atomic `static bool` flag. Concurrent first-use from multiple threads races.
**Fix:** Use `std::call_once`.

## LOW

### N18. Reliable Message Outbox Unbounded Growth
**File:** `Engine/src/Networking/NetworkSystem.cpp:856-878`
**Fix:** Cap outbox size.

### N19. EntityHandle Reference Count Not Atomic
**File:** `Engine/src/Scripting/ScriptBindings.cpp:240-249`
**Fix:** Use `std::atomic<int>`.

### N20. ScriptEventData Reference Count Not Atomic
**File:** `Engine/src/Scripting/ScriptBindings.cpp:545-551`
**Fix:** Use `std::atomic<int>`.

### N21. Network Sequence Number Wraparound Edge Case
**File:** `Engine/src/Networking/NetworkSystem.cpp:389-405`
**Fix:** Use modular arithmetic signed comparison.

### N22. `inet_addr()` Deprecation Returns Broadcast on Error
**File:** `Engine/src/Networking/NetworkTransport.cpp:34`
**Fix:** Use `inet_pton()` on all platforms.

# Part 2: Stability (15 findings)

## HIGH

### S1. `m_Physics2D` Never Initialized with World
**File:** `Engine/src/Editor/PlayMode.cpp:35`, `Player/src/main.cpp:217`
**Description:** `m_Physics2D` is created via factory but `Initialize(world)` is never called. Any 2D physics call operates on uninitialized backend — null dereference or undefined behavior.
**Fix:** Add `m_Physics2D->Initialize(world);` after creation in both files.

### S2. Entity Destruction During Script Iteration
**File:** `Engine/src/Scripting/ScriptBindings_Scene.cpp:139`, `Engine/src/Scripting/ScriptSystem.cpp:309-318`
**Description:** Script `OnUpdate()` can call `Scene_DestroyEntity()`, immediately destroying entities while `ScriptSystem::Update()` iterates cached script entities. Component pointer from `GetComponent` becomes dangling on self-destruction.
**Fix:** Implement deferred entity destruction queue, flush after all system updates.

### S3. Hot-Reload `DiscardModule` Invalidates Coroutine Contexts
**File:** `Engine/src/Scripting/ScriptEngine.cpp:597`
**Description:** `DiscardModule` destroys function metadata while active coroutines hold contexts referencing those functions. Next resume executes freed bytecode.
**Fix:** Abort all coroutines for the module before discard.

### S4. Static `baseOrthoSize` Shared Across All Camera2D Entities
**File:** `Engine/src/ECS/Systems/ControllerSystem.cpp:383`
**Description:** `static f32 baseOrthoSize` initialized from first entity processed, shared across all Camera2D entities. Multiple cameras use wrong base; value persists across play sessions.
**Fix:** Store `baseOrthoSize` per-entity on `Camera2DBoundsComponent`.

## MEDIUM

### S5. `m_Physics` Unchecked After Factory Create
**File:** `Engine/src/Editor/PlayMode.cpp:33`, `Player/src/main.cpp:216`
**Description:** `m_Physics->SetWorld(world)` called without null check. Factory returns nullptr if requested backend unavailable.
**Fix:** Add null guard.

### S6. Coroutine Resume Can Modify Vector During Iteration
**File:** `Engine/src/Scripting/CoroutineScheduler.cpp:60-91`
**Description:** `CoroutineScheduler::Update()` iterates `m_Coroutines` with range-based for. Resumed coroutines can call `StartCoroutine()` which push_back, potentially reallocating.
**Fix:** Use index-based loop with pre-captured count.

### S7. Vector Division by Zero in Script Bindings
**File:** `Engine/src/Scripting/ScriptBindings.cpp:96-98,144-146`
**Description:** `Vector2_opDivF` / `Vector3_opDivF` pass zero divisor through, producing Inf/NaN that propagates through physics and rendering.
**Fix:** Guard with epsilon check, return zero vector.

### S8. Sequence Node Recursion Without Depth Limit
**File:** `Engine/src/VisualScript/VisualScriptExecutor.cpp:329`
**Description:** Sequence nodes recursively call `ExecuteFlow` without the `MAX_CALL_DEPTH` limit that function-call nodes have.
**Fix:** Use the same depth counter for Sequence nodes.

### S9. Compute Submit Has No Fence
**File:** `Engine/src/Renderer/Vulkan/VulkanRenderer.cpp:614`
**Description:** `SubmitCompute()` uses `VK_NULL_HANDLE` fence. Multiple compute dispatches per frame could race.
**Fix:** Add per-frame compute fence or ensure single dispatch per frame.

## LOW

### S10. Separate `s_World` Pointers in Flower/Flash Bindings
**File:** `Engine/src/Scripting/ScriptBindings_Flower.cpp:16`, `Engine/src/Scripting/FlashAPIShim.cpp:20`
**Fix:** Reference shared `s_BindingsWorld` instead of separate pointers.

### S11. Zero-Length Raycast Direction Produces Zero Vector
**File:** `Engine/src/Scripting/ScriptBindings_Physics.cpp:60,75,124,139`
**Fix:** Check direction length, return early with no hit.

### S12. Pure Node Evaluation Unbounded Recursion on Cyclic Graphs
**File:** `Engine/src/VisualScript/VisualScriptExecutor.cpp:574-582`
**Fix:** Add recursion depth counter.

### S13. EntityHandle Reference Count Not Atomic
**File:** `Engine/src/Scripting/ScriptBindings.cpp:313`
**Fix:** Use `std::atomic<int>`.

### S14. ObjectPool.DestroyAll Redundant Before Scene Restore
**File:** `Engine/src/Editor/PlayMode.cpp:270`
**Fix:** Remove or move before ShutdownAllScripts.

### S15. vkQueueSubmit Failure Handling (Informational)
**File:** `Engine/src/Renderer/Vulkan/VulkanRenderer.cpp:357-362`
**Description:** Any submit failure treated as device lost. Current approach is correct (no Vulkan API to manually signal fences).

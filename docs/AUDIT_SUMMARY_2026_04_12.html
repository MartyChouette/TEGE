Fixes Applied 5 Issues Resolved

VulkanImage staging buffer never copied to GPU Critical
Engine/src/Renderer/Vulkan/VulkanImage.cpp:220
Staging buffer was allocated and filled with pixel data, then immediately freed without ever transferring to the device image. All textures loaded via CreateFromData (text, sprites, SVG, thumbnails) had undefined/garbage data. Added layout transition, vkCmdCopyBufferToImage, and final transition to shader-read-only.
ComponentRegistry type ID race condition Critical
Engine/include/Enjin/ECS/Component.h:25 · Engine/src/ECS/Component.cpp:6
s_NextComponentId++ was a plain integer increment. Concurrent first-registration of two component types could produce ID collisions, corrupting ECS storage. Changed to std::atomic<ComponentTypeId> with fetch_add.
MiniaudioBackend unsynchronized channel map Critical
Engine/include/Enjin/Audio/MiniaudioBackend.h:50 · Engine/src/Audio/MiniaudioBackend.cpp:77
m_Channels map accessed from Update() (erase), Play() (insert), Stop() (erase), and all SetChannel*() methods without any synchronization. Iterator invalidation under concurrent access could crash. Added std::mutex with lock guards on all 10 methods.
Command injection via system() in OpenInExplorer High / Security
Engine/src/Editor/EditorLayerProjectHub.cpp:180
std::system("open \"" + folderPath + "\"") on macOS/Linux. A project folder named foo"; rm -rf /; # would execute arbitrary shell commands. Replaced with fork()/execlp() which bypasses the shell entirely.
Cascade shadow stagger offset collision Logic
Engine/src/ECS/Systems/RenderSystem.cpp:6275
Cascade 2 received the same stagger offset (0) as cascades 0 and 1, causing all three to update on the same frame instead of distributing load. Changed (cascade - 2) to (cascade - 1).

# Progress

Working toward 1.0 in summer 2027. The big pieces, ticked when they work end to end.

## Engine and runtime

- [x] Entity component system, scenes, prefabs
- [x] Physics in 2D and 3D
- [x] Scripting, and visual scripting alongside it
- [x] Audio with spatialization and event graphs
- [x] Save, quest, dialogue and cinematic systems
- [x] Time rewind and shareable replays
- [ ] Particle system rebuild
- [ ] Streaming and crowd scale

## Rendering and art direction

- [x] PBR rendering, shadows, post-processing, reflection probes
- [x] Art style presets and retro rendering modes
- [x] Weather, water, vegetation, cloth
- [x] Procedural generation: dungeons, terrain, scatter, wave function collapse
- [ ] Ray tracing out of experimental
- [ ] Custom art styles without writing shader code

## Authoring tools

- [x] Scene editing, gizmos, undo, command palette
- [x] Shader graph, dialogue trees, animation graphs
- [x] Pixel editor, vector drawing, sprite sheet import
- [ ] Terrain sculpting
- [ ] Tilemap painter
- [ ] Visual UI layout editor
- [ ] Texture and vertex weight painting

RT status Eyeball me

Everything on the RT path renders and displays now. "Unfinished" is correctness polish and non-visual plumbing, not missing pixels.

On screen now

  • Path tracing, full: raw, SVGF, OIDN. End to end at swapchain res, converges ~300spp.
  • Mixed RT: shadows, AO, reflections, GI all display. All four differ from the raster baseline.
  • Vegetation, water, sky in the TLAS: PT metal reflects the greenery, sky matches raster.
  • Stable + clean: matrix 14/14, player probe 0 errors, suite 101/101, no crash.

Unfinished (what it means when you look)

  • Hybrid rchit real shading: reflections / GI / caustics / translucency use fake normals + fake NdotL. Only the path tracer reads true geometry normals, so hybrid reflection/GI color is approximate. Expected, not a bug.
  • Goldens not blessed: the captures in goldens/rt/_candidates are candidates, not references. Nothing regression-guards RT until you -Record.
  • Async RT forced off (raced the G-buffer + overlay). Single-queue only.
  • Skinned meshes ray-trace in bind pose (TLAS uses unskinned vertex buffers).

How to check: open the per-variant PNGs in goldens/rt/_candidates (fastest), or open the RT probe project in the editor and toggle modes in Scene Settings. Compare each rt_* to raster_base: shadows/AO darken contact, reflections/GI add bounce, path tracer looks fully lit and converged. Judge whether the approximate hybrid color ships; the rest is 0.9.8 polish.

C. To 1.0 (October 2026) Long haul

Rendering

  • Hybrid RT + DDGI + surfel GI visually complete and demo-able.
  • Editor/player render parity: one code path. Every latent bug this week (shadow binds, TLAS lifetime, clustered, fog usage flags) hid in whichever loop does not run. This is the structural fix.
  • SMAA shaders; VRS content-adaptive and motion modes; player post-process chain parity.

Platforms

  • Web parity completion: textured sprites, UI/text render path, accessibility overlays.
  • Then Android (Vulkan), then iOS/Metal (backend currently empty).

Architecture consolidation

  • Retire AudioManager (SimpleAudio is the system). Retire legacy AIAgent. ConstraintSolver decision.
  • Visual-script globals into ExecutionContext.
  • World.h per-GetComponent recursive_mutex; per-frame DrawCmd alloc and sort; ECS archetype storage evaluation.

Pipeline honesty

  • Real .enjpak compression (currently passthrough). Pak-only exports (loose files still ship).
  • Quest custom conditions (always return true). Navmesh agentRadius (documented, ignored). Click-to-move.
  • Server authority (currently allow-all). Collab component-removal sync (3 of 140 types).

Editor authoring tools

  • Navmesh generation + visualization UI. Terrain sculpting. Tilemap painter. Visual UI layout editor. Template preview images.

Scripting and serialization surface

  • Remaining unbound components (joints, colliders, tilemap, hierarchy bound in the May cleanup; ~35 remain).
  • Component serializer coverage from ~7% round-trip-tested toward full; mid-play save state (AI, audio, tweens).
  • SCRIPTING_API doc gaps (HasComponent coverage, AI bindings, Camera_ApplyPreset).

Docs

  • ARCHITECTURE.md drift (MaterialGPU 80 to 112, backend phases). Dual-system explanations. RT shader workflow. ROADMAP refresh against this document.

Parked (1.0+ or cut, Marty's call)

## Fixes Applied (2026-04-12)

### FIX-1. VulkanImage::CreateFromData — staging buffer never copied to GPU [CRITICAL]
**File:** `Engine/src/Renderer/Vulkan/VulkanImage.cpp:220-230`
**Was:** Staging buffer allocated, pixel data copied in, then freed without `vkCmdCopyBufferToImage`. Comment said "simplified for now." All textures loaded via this path had undefined/garbage data.
**Fix:** Added one-shot command buffer with layout transition (UNDEFINED -> TRANSFER_DST), buffer-to-image copy, and final transition (-> SHADER_READ_ONLY). Used by text textures, sprite atlases, SVG loader, thumbnails.

### FIX-2. ComponentRegistry::s_NextComponentId — non-atomic increment [CRITICAL]
**File:** `Engine/include/Enjin/ECS/Component.h:25`, `Engine/src/ECS/Component.cpp:6`
**Was:** `static ComponentTypeId id = s_NextComponentId++` — plain integer increment. Concurrent first-registration of two component types could produce ID collision.
**Fix:** Changed to `std::atomic<ComponentTypeId>` with `fetch_add(1, memory_order_relaxed)`.

### FIX-3. MiniaudioBackend — unsynchronized m_Channels map [CRITICAL]
**File:** `Engine/include/Enjin/Audio/MiniaudioBackend.h`, `Engine/src/Audio/MiniaudioBackend.cpp`
**Was:** `m_Channels` map accessed from `Update()` (erase finished sounds), `Play()` (insert), `Stop()` (erase), and all `SetChannel*()` methods without any synchronization. Iterator invalidation under concurrent access.
**Fix:** Added `std::mutex m_ChannelMutex` with `std::lock_guard` on all 10 methods that access `m_Channels`.

### FIX-4. OpenInExplorer — command injection via system() [HIGH/SECURITY]
**File:** `Engine/src/Editor/EditorLayerProjectHub.cpp:180-191`
**Was:** `std::system("open \"" + folderPath + "\"")` on macOS/Linux. A project folder named `foo"; rm -rf /; #` would execute arbitrary shell commands.
**Fix:** Replaced with `fork()`/`execlp()` which passes the path as a direct argument, not through a shell. Windows was already safe (`ShellExecuteA`).

### FIX-5. Cascade shadow stagger — duplicate offset [LOGIC]
**File:** `Engine/src/ECS/Systems/RenderSystem.cpp:6275`
**Was:** `offset = (cascade <= 1) ? 0 : (cascade - 2)` — cascade 2 got offset 0, same as cascades 0/1, defeating the stagger.
**Fix:** Changed to `(cascade - 1)` so each far cascade updates on a different frame.

## Remaining Issues — CRITICAL

### CR-1. Heap buffer overflow in cgltf path concatenation
**File:** `Engine/include/cgltf.h:1288-1292`
**Risk:** Remote code execution via malicious glTF file
**Description:** `cgltf_combine_paths()` uses `strcpy()` without bounds. Buffer allocated as `strlen(uri) + strlen(gltf_path) + 1` doesn't account for the prefix bytes from the base path. Long URI + long base path overflows the heap buffer.
**Status:** Not fixed (third-party header — requires upstream patch or local override).

### CR-2. Integer overflow risk in terrain splatmap
**File:** `Engine/src/Scene/SceneSerializer.cpp:824`
**Description:** `static_cast<usize>(terrain.gridWidth) * terrain.gridHeight * 4` — multiplication by 4 is safe on 64-bit but could overflow on 32-bit platforms where `usize` is 32-bit.
**Status:** Not fixed. Low risk (engine targets 64-bit only).

### CR-3. VulkanImage layout stays UNDEFINED for failed transfers
**File:** `Engine/src/Renderer/Vulkan/VulkanImage.cpp`
**Description:** If the command buffer submission in CreateFromData fails, the image remains in UNDEFINED layout but CreateImageView succeeds. Subsequent shader sampling of this image is a Vulkan spec violation.
**Status:** Partially mitigated by FIX-1 (transfer now happens). Full error recovery not yet implemented.

## HIGH Fixes Applied (Round 2 & 3)

### FIX-6. m_DeviceLost — non-atomic bool [THREAD SAFETY]
**File:** `Engine/include/Enjin/Renderer/Vulkan/VulkanRenderer.h:166`
**Fix:** Changed `bool m_DeviceLost` to `std::atomic<bool> m_DeviceLost{false}`.

### FIX-7. NameCache rebuilt without lock [THREAD SAFETY]
**File:** `Engine/src/ECS/World.cpp:137`
**Fix:** Added `std::lock_guard<std::recursive_mutex>` to `FindEntityByName`, protecting both cache rebuild and lookup.

### FIX-8. GLTFLoader null dereference [MEMORY SAFETY]
**File:** `Engine/src/Assets/GLTFLoader.cpp:62`
**Fix:** Added null checks for `buffer_view->buffer` and `buffer->data` before dereferencing.

### FIX-9. MSAA framebuffer creation leaks on failure [VULKAN]
**File:** `Engine/src/Renderer/Vulkan/VulkanSwapchain.cpp:389`
**Fix:** On `vkCreateFramebuffer` failure, now destroys all previously-created framebuffers and returns early (both MSAA and non-MSAA paths).

### FIX-10. Audio occlusion O(n*m) nested loop [PERFORMANCE]
**File:** `Engine/src/Audio/AudioReactiveSystem.cpp:615`
**Fix:** Cached `GetEntitiesWithComponent<BoxColliderComponent>()` before the outer per-source loop. O(n*m) -> O(n+m).

### FIX-11. Double AnimatorComponent iteration [PERFORMANCE]
**File:** `Engine/src/ECS/Systems/RenderSystem.cpp:978-988`
**Fix:** Merged two consecutive loops (Update + IK) into a single pass over AnimatorComponent entities.

### FIX-12. Per-entity global animator search [PERFORMANCE]
**File:** `Engine/src/ECS/Systems/RenderSystem.cpp:2161`, `Engine/include/Enjin/ECS/Systems/RenderSystem.h:613`
**Fix:** Added `m_CachedFallbackAnimator` computed once per frame during the animator update loop. Orphan skinned meshes now use this cached pointer instead of searching all animators per entity in the render loop.

### FIX-13. Visual script global pointer thread safety [THREAD SAFETY]
**File:** `Engine/src/VisualScript/NodeRegistry.cpp:50-87`
**Fix:** Added thread safety contract comment documenting main-thread-only access. Full atomic conversion deferred to ExecutionContext refactor (30+ extern sites, both reads/writes are main-thread).

## Remaining Issues — MEDIUM

### Thread Safety
- `m_MasterVolume` read/written without sync in MiniaudioBackend (note: channel access now protected, volume is simple float)
- Recursive mutex in `World.h` masks lock ordering issues
- Virtual texture `m_StreamingActive` uses seq_cst where relaxed suffices

- `vkResetCommandBuffer` return unchecked (`VulkanRenderer.cpp:810`)

- Missing depth aspect mask detection in `TransitionLayout`
- Sampler leak in `CreateDefaultSampler` (never tracked for cleanup)
- Generic `ALL_COMMANDS_BIT` fallback barriers hide bugs

### Performance

- String `+=` concatenation ~30 times in report builder (`FeedbackSystem.cpp`)
- `m_IKChainCache.resize(3)` called every IK frame
- Full material entity iteration on texture hot-reload
- Per-entity hash lookups for text texture cache in render loop
- Mid-frame GPU buffer creation for bone buffers
- Multiple `GetOrLoadTexture` hash lookups per entity per frame

### Logic

# TEGE — Full Project Review (2026-08-21)

A cross-cutting audit of the engine, its website, its GitHub presence, its
documentation + user manual, and its top development risks. Produced by four
parallel read-only audits, cross-verified against the actual code at commit
`aed36fd`. Where an audit corrected a stale assumption (e.g. a bug that has since
been fixed), that is called out — several of the scariest historical items are
already resolved.

## CRITICAL — do these first

1. ~~**Open RCE in `Engine/include/cgltf.h` (heap overflow via malicious glTF).**~~
   **RESOLVED / FALSE ALARM (verified 2026-08-21).** On direct inspection
   `cgltf_combine_paths()` (`cgltf.h:1277`) already carries the **SEC-C1 fix**: it
   takes a `path_size` param and uses bounded `strncpy`/`snprintf`; the caller
   (`:1310`) passes a correctly-sized buffer (`strlen(uri)+strlen(gltf_path)+1`,
   which bounds `prefix ≤ strlen(gltf_path)` plus the uri). A grep of `cgltf.h`
   for `strcpy`/`strcat`/`sprintf` returns nothing. The April CR-1 was patched;
   the audit agent misread the fix comment as the vulnerability. No action needed.

2. **~65 MB of stale release ZIPs are committed in `installer/output/`.**
   Tracked archives for 0.8.0 / 0.8.5 / 0.9.0 / 0.9.5 (incl. a 22 MB "0.9.5 Full.zip").
   `.git` is 231 MB on disk largely because of this. `.gitignore:162` already means to
   exclude them — they predate the rule. Every clone pays for it. `git rm --cached`
   them (ship binaries via Releases, already done for 0.9.7) and ideally history-rewrite.

3. **Wrong scene file extension `.enjscene` in the authoritative reference tables.**
   Real extension is `.enjin` (verified in `EditorLayerMenuBar.cpp` filters). Wrong in
   `docs/USER_MANUAL.md:3419`, `docs/TUTORIALS.md:2513`, `docs/manual.html` (×2).
   Global replace `.enjscene` → `.enjin`.

## HIGH

4. **The serializer has hit a hard compiler limit and silently loses data.**
   `SceneSerializer.cpp` (12k lines) drives per-component logic through a ~140-entry
   else-if chain that already **saturates MSVC's C1061 block-nesting limit**
   (`:11304`) — which is why GPUParticleEmitter and Swarm silently fell out of
   undo/redo. A typical component touches the serializer in **20–40 hand-maintained
   sites** (adding the 5 procgen components this week meant editing ~11 sites each).
   "Unknown entity keys are silently erased on next save" is the same class. **This is
   the highest-leverage refactor in the codebase:** move to table/registration-based
   dispatch (component type → serialize/deserialize/remove trio) so a new component
   registers once. Retires C1061 permanently and turns silent data-loss into a
   compile/test-time failure.

5. **Repo working-tree clutter + `.gitignore` gaps.**
   79 untracked entries: 29 `_*.ps1`/`_*.py` probe scripts at root, `build_release.bat`,
   `vk_layer_settings*.txt`, `web-demo/__pycache__/`, and 37 unused imgui backends
   (dx9-12, metal, sdl, etc.) from a full upstream checkout. `git check-ignore` confirms
   none of the probe scripts are ignored — one `git add -A` from polluting the repo, and
   on a bus-factor-1 project this is also **unbacked-up work at risk**. Add ignore rules
   (`/_*.ps1 /_*.py /_*.bat vk_layer_settings*.txt __pycache__/`), prune the unused imgui
   backends. (Note: CLAUDE.md's claim that `third_party/imgui` is "an untracked nested git
   clone" is now **stale** — imgui is tracked normally, no `.git` inside. Update that trap.)

6. **LICENSE is stale and reads as unclassified.**
   Says `Licensed Work: The Enjin Game Engine 0.8.0` (repo is 0.9.7) and a hardcoded
   `Change Date: 2030-03-07` that contradicts the README's "Apache 2.0 four years after
   each release" model. GitHub can't classify BSL 1.1 → shows "Other" with no license
   chip. Bump the version, reconcile the change-date language, add a plain-English BSL
   summary. (BSL 1.1 is a fine choice for the free-source-now / paid-1.0 model — just make
   it legible.)

7. **Tutorial 1 — the first thing a new user does — fails against the real editor.**
   Step 1 says pick template **"Empty Scene"** (real name: **"Blank"**). Step 4 says set a
   **Direction** field on LightComponent that **does not exist** (direction derives from
   Transform rotation; the field is only on the GPU struct). Fix both in
   `docs/TUTORIALS.md`.

8. **BUILD.md flatly contradicts every other doc on ray tracing.**
   `docs/BUILD.md:324` calls RT "placeholder stubs — replace them to activate"; CLAUDE_REFERENCE,
   DEVJOURNAL, and ROADMAP all say RT ships compiled and auto-activates (and disagree 19 vs 25
   on shader count). BUILD.md is the getting-started entry point telling builders a flagship
   feature is dead. Rewrite to the shipped state; unify the shader count.

9. **Three overlapping manuals with no stated canonical.**
   Root `MANUAL.md` (34 KB, stale) still frames the engine as "retro PS1/PS2-era" — the *old*
   identity, now just 1 of 9 art styles. Plus `docs/USER_MANUAL.md` (current, 204 KB) and
   `docs/manual.html` (generated, 582 KB, carries the `.enjscene` bug). Declare USER_MANUAL
   canonical, retire/redirect MANUAL.md, regenerate the HTML from the corrected source.

10. **Website: "686 API bindings" vs README "1,000+".** A visitor reading both sees a factual
    conflict (the ~1,010 / "1107-call sweep" figure is closer to real). Pick one number and use
    it everywhere. Also: the site **hides** its strongest credibility signal ("1,900+ / 2027
    passing tests") and has **no Open Graph / Twitter card metadata**, so shares to Discord/X/Reddit
    (this engine's actual channels) render as bare URLs. Add og:* tags + a test-count trust badge.

## MEDIUM

11. **CI can't reach the paths where the worst bugs live.** `ci.yml` genuinely builds with tests
    ON and runs `ctest` (the "1900+ passing" claim is real — 2027 cases; premise that CI is
    stale/red was **wrong**, it's green). But no GPU on runners → renderer, RT, WebGPU, editor,
    web-runtime are validated only by local eyeball/golden probes, and those are exactly where the
    fossil-shader / mid-frame-destruction / web-depth bugs happened. **Add a lavapipe/SwiftShader
    software-GPU golden-image smoke pass to CI.**

12. **Downloads route off-GitHub despite Releases being populated.** README/site point at
    `marty64.net/…zip`; the v0.9.7 GitHub Release already hosts both assets. Point at least one
    link at the Release (checksums, changelog, counts). Clear the stale **0.9.6 draft** release.

13. **Feature-count drift everywhere erodes trust.** Tests 1900+/~1100/2027; VS nodes 256/262;
    art styles 8/9/7; bindings 480/686/1000/1010; tutorials "55" (really 54). Establish canonical,
    ideally generated, numbers. INDEX.md's "~480 functions" and Physics description are badly out
    of date (still describes a pre-Jolt "SimplePhysics/PhysicsWorld" architecture).

14. **Stale-binary build traps.** Export ships a **prebuilt `EnjinPlayer.exe`** found by an
    8-path search — stale if not rebuilt after engine changes (has bitten before).
    `file(GLOB_RECURSE)` needs manual reconfigure on new files. imgui MRT patch must be
    re-applied by hand. Make `EnjinPlayer` a build dependency of export + stamp a build hash;
    move to explicit source lists; vendor imgui with the patch pre-applied.

15. **Missing community/meta files.** No SECURITY.md (notable given the README's candid "I cannot
    guarantee security" — no way to report a vuln), no CHANGELOG, no CODE_OF_CONDUCT. Present:
    CONTRIBUTING, issue/PR templates, NOTICE, THIRD_PARTY_LICENSES, `.enjin-boundaries.json`.

16. **AUDIT docs presented as current status without a resolution overlay.** INDEX advertises
    "55 findings, 42 remaining" / "38 findings, 35 resolved" from April, but later work closed many.
    A reader treats stale Critical/High items as the live posture. Add a dated resolution banner/column
    or archive superseded audits. **(This review doc is the current rolling snapshot.)**

17. **Website scope accuracy:** omits Linux (README claims it); presents experimental RT/path-tracing
    as shipped; no lazy-loading on 27 gallery images; demo is click-to-play WebGPU with no
    "best in Chrome/Edge" guidance (silent failure on Safari/Firefox).

## Bus-factor of one (systemic)

260k lines: Vulkan (full) + WebGPU (partial) + Metal (**zero files — unbuilt**) + Jolt + Box2D +
RT + AngelScript + VisualScript + editor + web + networking + 140+ components, all one developer.
Most correctness invariants live in CLAUDE.md's "Traps & Rules" prose, not the type system
(descriptor binding-2 contract, 2D/3D physics separation, web Y-flip, `firstInstance`→material-index).
This is not fixable, only mitigable: keep converting the highest-consequence conventions from prose
into enforced code (asserts / static_asserts / typed wrappers / tests) — the engine already does this
well for `MaterialGPU` size and ADR-0004; extend the pattern. Optimize for your future self over
multi-dev scale.

## Credit — flagged concerns that are ALREADY fixed

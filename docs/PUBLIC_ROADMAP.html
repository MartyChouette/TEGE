Vision & Strategy

Enjin is an open-source (BSL 1.1) game engine built with C++20 and Vulkan. The engine has reached a breadth milestone of 150+ features — the next phase shifts from feature expansion to depth and stability.

Core Principles

  • Quality gates over feature velocity — nothing ships until audited, tested, and documented
  • Tiered maturity — every subsystem has an explicit stability level (Stable → Beta → Preview → Experimental)
  • Feature flags — non-core systems are behind CMake options or runtime toggles, keeping the core lean
  • Public accountability — this roadmap is the source of truth for what's ready and what's not

Development Pipeline

Every feature goes through a five-stage pipeline before reaching Stable status. No shortcuts — each gate must be passed.

Audit Methodology

Each subsystem goes through a structured audit before promotion. The audit process is the same whether the system is being promoted from Implementation → Beta or Beta → Stable.

Per-Subsystem Checklist

  • Input validation — all external data (JSON, files, scripts, network) validated at trust boundaries
  • Error handling — no silent failures, graceful degradation, log meaningful messages
  • Resource management — no leaks (GPU buffers, file handles, allocations), proper cleanup on shutdown
  • Thread safety — document threading model, no data races, mutex scope minimized
  • Performance — no O(N²) in hot paths, allocations amortized, cache-friendly access patterns
  • API surface — minimal public API, const-correct, no raw pointers in public interfaces where avoidable

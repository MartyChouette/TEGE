## PART 1: SECURITY

### 1A. Vulkan/Rendering Security (18 findings)

#### CRITICAL

**S1. Unvalidated Command Buffer Array Access**
`Engine/src/Renderer/Vulkan/VulkanRenderer.cpp:471`
`GetCurrentCommandBuffer()` returns `m_CommandBuffers[m_CurrentFrame]` without bounds check. If `m_CurrentFrame` exceeds `MAX_FRAMES_IN_FLIGHT`, out-of-bounds access occurs.
**Fix:** Add `assert(m_CurrentFrame < MAX_FRAMES_IN_FLIGHT)`

**S2. Same Issue with Compute Command Buffers**
`Engine/src/Renderer/Vulkan/VulkanRenderer.cpp:577`
`GetCurrentComputeCommandBuffer()` checks if empty but not if `m_CurrentFrame` is valid index.
**Fix:** Add `if (m_CurrentFrame >= m_ComputeCommandBuffers.size()) return VK_NULL_HANDLE;`

**S3. Unchecked vkBeginCommandBuffer in TransitionLayout**
`Engine/src/Renderer/Vulkan/VulkanImage.cpp:267`
`vkBeginCommandBuffer()` result not checked. Failed begin + subsequent `vkCmdPipelineBarrier()` = memory corruption or GPU hang.
**Fix:** Check result before proceeding.

**S4. Same Unchecked vkBeginCommandBuffer in GenerateMipmaps**
`Engine/src/Renderer/Vulkan/VulkanImage.cpp:369`

**S5. Unchecked vkQueueSubmit in Compute Path**
`Engine/src/Renderer/Vulkan/VulkanRenderer.cpp:612`
`SubmitCompute()` ignores `vkQueueSubmit()` result. Failed submit + fence never signaled = potential deadlock.
**Fix:** Check result, set `m_DeviceLost = true` on failure.

#### HIGH

**S6. Multi-Frame Semaphore Race in Async Compute**
`VulkanRenderer.cpp:329-342` — Compute semaphore from frame N-1 could collide with frame N if compute is still processing.

**S7. Missing Error Handling on vkMapMemory**
`VulkanImage.cpp:171` — Mapped buffer not properly flushed/unmapped on error paths.

**S8. Integer Truncation in Buffer Offset**
`VulkanBuffer.cpp:91` — `offset` is `usize` (64-bit), used in pointer arithmetic without separate overflow check.

**S9. Dangling Context Pointer in VulkanImage**
`VulkanImage.cpp:237` — `m_Context` checked for null but could be dangling pointer during cleanup.

#### MEDIUM

**S10.** No device lost recovery mechanism (permanent renderer death)
**S11.** Unchecked framebuffer creation failures (uninitialized handles)
**S12.** Compute semaphore array accessed without init check
**S13.** vkQueueSubmit unchecked in VulkanImage operations

#### LOW

**S14.** Temporary command pool leak if vkQueueWaitIdle hangs
**S15.** Mipmap generation silently fails on unsupported formats
**S16.** Swapchain image count not re-validated after second call
**S17.** log2(0) undefined behavior if width/height is 0
**S18.** FindMemoryType UINT32_MAX not checked before vkAllocateMemory

### 1B. Serialization/Assets Security (15 findings)

#### HIGH

**S19. Unsafe JSON Array Access Without Bounds Check**
`Engine/src/Scene/SceneSerializer.cpp:5161`
`sj["topColor"]` accessed as `a[0], a[1], a[2]` after only `.contains()` check — no `.is_array()` or `.size() >= 3` validation. Malformed JSON with incomplete arrays causes out-of-bounds.
**Fix:** Add `&& sj["topColor"].is_array() && sj["topColor"].size() >= 3`

**S20. Unsafe Enum Casting Without Range Validation**
`SceneSerializer.cpp:312, 370, 412, 5160`
Enum values cast via `static_cast` without validating range. Out-of-range values cause undefined behavior.
**Fix:** Validate `val >= 0 && val < MAX_ENUM` before casting.

**S21. Integer Overflow in AssetReader Path Length**
`Engine/src/Build/AssetReader.cpp:113-120`
`pos += pathLen` can overflow if `pathLen` is near `u32` max.
**Fix:** Check `pos > indexBuf.size() - pathLen` before addition.

**S22. Direct JSON Array Access Without Validation (Multiple)**
`SceneSerializer.cpp:2103, 2108, 2116` — `boxColor`, `origin`, etc. accessed without `.is_array()` or size check.
**Fix:** Use existing `DeserializeVector3()` helper which has proper bounds checking.

#### MEDIUM

**S23.** Missing type validation on JSON array elements in DataAsset
**S24.** Unbounded vertex/index allocation from glTF accessor count
**S25.** Missing inner type validation in JSON vertex deserialization
**S26.** Inconsistent path traversal checking (sprites/audio not validated)
**S27.** Cubemap paths loaded without traversal validation
**S28.** Size truncation u64→u32 in AssetPacker path length
**S29.** Unchecked matrix element access in deserialization

#### LOW

**S30.** Missing null pointer check on smart pointers in Prefab
**S31.** XOR obfuscation is trivially broken (documented/known)
**S32.** Missing file.good() immediately after ifstream open
**S33.** Inconsistent array size validation patterns across codebase

### 1C. Scripting/Networking/Plugin Security (18 findings)

#### CRITICAL

**S34. Command Injection in Hot Reload**
`Engine/src/Plugin/HotReload.cpp:182`
`std::system(m_CompileCommand.c_str())` — compile command passed directly to shell without validation or escaping. Arbitrary command execution.
**Fix:** Replace with `CreateProcess()` / `fork()+exec()` with explicit argument passing.

**S35. Command Injection in Editor Git Init**
`Engine/src/Editor/EditorLayer.cpp:11754-11759`
Project path concatenated into `cd "path" && git init` — shell metacharacter injection via project name.
**Fix:** Use `CreateProcess()` or git library.

**S36. Command Injection in IDE Opener**
`Engine/src/Editor/EditorLayer.cpp:22620`
File paths from user data passed to `std::system()`.
**Fix:** Use native APIs (`ShellExecute`, etc.)

**S37. Unsafe DLL Loading Without Signature Verification**
`Engine/src/Plugin/PluginSystem.cpp:100-115`
`LoadLibraryA()` / `dlopen()` with no signature check, path validation, or sandboxing. DLL hijacking possible.
**Fix:** Implement Ed25519 signature verification. Use `LOAD_LIBRARY_SEARCH_DLL_LOAD_DIR`.

**S38. Unsafe URL Port Parsing**
`Engine/src/Networking/HTTPClient.cpp:44-46`
`std::stoi()` on port string — integer overflow (999999 → u16), exception-based DoS.
**Fix:** Bounds-check parsed port value 1-65535.

#### HIGH

**S39.** No URL encoding in HTTP form data — injection via `&` and `=` chars
**S40.** JSON injection in Newgrounds API — `m_AppId` and `m_Session.id` not escaped
**S41.** Vulnerable string-based JSON parsing in Newgrounds — `npos` overflow
**S42.** No RPC function whitelist — any client can invoke any registered RPC
**S43.** Network packet payload size not fully validated in all handlers

#### MEDIUM

**S44.** Weak string-based JSON parsing in Newgrounds medal system
**S45.** Script #include path traversal not restricted to script directory
**S46.** AngelScript instruction limit bypassable (memory exhaustion, one-line loops)
**S47.** No player authentication on LAN connect — name spoofing
**S48.** Silent string truncation at 255 bytes in network serializer

#### LOW

**S49.** Unvalidated shell command check via `which`
**S50.** Newgrounds API key/secret stored plaintext in memory
**S51.** No per-connection packet rate limiting

## PART 2: STABILITY

### 2A. ECS/Physics Stability (12 findings)

#### CRITICAL

**T1. Dangling Entity References After Deletion**
`Engine/src/ECS/World.cpp:28-63`
`DestroyEntity()` doesn't notify systems that cache entity IDs. Stale IDs → use-after-free.
**Fix:** Implement deferred destruction queue or generation IDs.

**T2. Null Pointer Dereference in Constraint Solver**
`Engine/src/Physics/ConstraintSolver.cpp:21-27`
`rbA->mass` accessed after initial null check — component could be removed between check and access.
**Fix:** Cache all pointers early and validate simultaneously.

**T3. Missing IsValid() Before Component Access in FlowerSystem**
`Engine/src/ECS/Systems/FlowerSystem.cpp:688-699`
Iterating `InteractableComponent` entities, accessing `TagComponent` without `IsValid()` check.
**Fix:** Add `if (!m_World->IsValid(other)) continue;`

**T4. Race Between Physics Sync and Entity Destruction**
`JoltBackend.h` / `Box2DBackend.h`
Entity-to-body mappings become stale if entity destroyed during physics step.
**Fix:** Add synchronization barriers or deferred removal queues.

#### HIGH

**T5.** Iterator invalidation risk in DialogueSystem if entity removed during playback
**T6.** Missing component validation in constraint solver joint operations (rbA/rbB stale)

#### MEDIUM

**T7.** Uninitialized quaternion edge case in transform matrix construction
**T8.** Division by zero with 1e-6 epsilon threshold in controller normalization
**T9.** NaN propagation from zero-scale transforms through rendering pipeline
**T10.** Stack overflow risk with 1000-level hierarchy depth limit (no warning)

#### LOW

**T11.** Name cache silently overwrites duplicate entity names
**T12.** Floating point precision drift in physics constraint solver epsilon

### 2B. Editor/GUI/Audio Stability (18 findings)

#### CRITICAL

**T13. PlayMode Camera Null Pointer Race**
`Engine/src/Editor/PlayMode.cpp:423-475`
`SaveEditorState()` checks `!m_Camera` then accesses it — pointer could become null between check and use.
**Fix:** Capture pointer locally before use.

**T14. RenderSystem Null in Play Mode**
`PlayMode.cpp:174-176`
`m_RenderSystem` used without initialization validation.
**Fix:** Check `m_RenderSystem && m_RenderSystem->IsInitialized()`

**T15. Physics Backend Null Dereference in Update**
`PlayMode.cpp:310, 315, 335`
`m_Physics->Update(deltaTime)` called without null check. If `CreatePhysicsBackend()` returns null → crash.
**Fix:** Add `if (m_Physics) { ... }` guard.

**T16. PlayModeDiff JSON Bounds Unchecked**
`Engine/src/Editor/PlayModeDiff.cpp:86-96`
JSON parsing doesn't validate structure before accessing entity names. Malformed scene → uncaught exception.
**Fix:** Add try-catch wrapper and structural validation.

**T17. UISystem Reverse Iteration Underflow**
`Engine/src/GUI/UISystem.cpp:176-177`
If `canvas.elements.size()` is 0, `i = -1` cast to `usize` wraps to max value → out-of-bounds.
**Fix:** Add bounds check inside loop.

#### HIGH

**T18.** ImGui descriptor pool exhaustion (1000 max sets, no cleanup)
**T19.** Animation PingPong frame underflow (size-2 wraps on 1-frame anims)
**T20.** Weather system NaN/Inf camera position propagation
**T21.** Dialogue node removal during iteration → iterator invalidation
**T22.** Particle resize truncates active particles (dangling state)

#### MEDIUM

**T23.** Crash on entity select in scene without camera
**T24.** Dialogue file I/O errors unhandled (no atomic writes)
**T25.** Undo/redo exception leak (partial state modification)
**T26.** Empty scene physics update without early-exit
**T27.** Post-processing null after failed initialization

#### LOW

**T28.** Dialogue variables map grows unbounded (never cleared)
**T29.** Weather lightning flag race condition (not atomic)
**T30.** ImGui font fallback chain fragile (no warning on heading fail)

## PART 3: PERFORMANCE (17 findings)

### Critical Impact

**P1. GetAllEntities() Loops in EditorLayer (17+ occurrences)**
`Engine/src/Editor/EditorLayer.cpp:2428 + 16 others`
Full entity iteration with 8+ sequential `HasComponent` checks per entity, every frame.
**Fix:** Replace with `GetEntitiesWithComponent<T>()` per type.
**Impact:** 10-50x faster on 1000+ entity scenes.

**P2. Redundant HasComponent + GetComponent Pattern**
`Engine/src/ECS/Systems/RenderSystem.cpp:3731-3799`
`HasComponent()` call followed by `GetComponent()` = duplicate map lookup per entity in sprite/tilemap loops.
**Fix:** Just call `GetComponent()` and check for null.
**Impact:** ~5-10% faster sprite/tilemap rendering.

**P3. Player Entity Full Scan with 5 Component Checks**
`EditorLayer.cpp:1628-1637`
Cache invalidation runs 5 `HasComponent` calls on cached entity + full `GetAllEntities()` fallback scan.
**Fix:** Query each controller component type separately with early exit.
**Impact:** 5-20x faster player entity lookups.

### High Impact

**P4. ObjectData Upload Reiterates Same Entities**
`RenderSystem.cpp:2001-2076`
`UploadObjectData()` re-queries and re-filters the same entities as `BuildCullableObjectList()`.
**Fix:** Iterate `m_CullableObjects` directly.
**Impact:** 3-5x faster GPU culling data uploads.

**P5. Scene Composition Classified Every Frame**
`RenderSystem.cpp:1795-1850`
Full entity iteration across sprites/tilemaps/meshes/lights every frame.
**Fix:** Cache with dirty flag, only recompute on component add/remove.
**Impact:** 5-15% faster frame times on heavy scenes.

**P6. Ray-Sphere Picking Without Spatial Partitioning**
`FlowerSystem.cpp:117-139`
All grabbable entities tested linearly on every click.
**Fix:** Build spatial grid of grabbables.
**Impact:** 5-20x faster in dense scenes.

### Medium Impact

**P7.** 3 separate zone containment loops every frame (camera/weather/temp) — combine or spatial index
**P8.** Visual script `FindEntityByName` does O(N) full scan — use World name cache
**P9.** UISystem canvas vector allocated + sorted every frame — cache with dirty flag
**P10.** ParticleSystem uses `std::rand()` (~50 cycles) — replace with xorshift32 (~5 cycles)
**P11.** Material `castShadows` check requires full component lookup per shadow entity

### Low Impact

**P12.** Vector allocations without `reserve()` in RenderSprites
**P13.** String allocations in component search filter
**P14.** JSON serialization without streaming for large scenes
**P15.** Material parsing uses manual `find()` instead of JSON library
**P16.** Per-entity texture descriptor writes despite caching
**P17.** Shadow caster reserve estimate doesn't account for filtered entities

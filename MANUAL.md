# Enjin Engine Manual (moved)

This file used to carry an early copy of the manual, written when the engine
was framed as a retro-only (PS1/PS2-era) engine. That framing and the copy here
went stale, so it has been retired in favor of the maintained docs:

- **[Beginner's Guide & Cheat Sheet](docs/BEGINNERS_GUIDE.md)** - start here:
  clone to exported game in 10 minutes, plus a standing quick reference.
- **[User Manual](docs/USER_MANUAL.md)** - the canonical, complete manual
  (components, editor, workflows). HTML version: `docs/manual.html`.
- **[Tutorials](docs/TUTORIALS.md)** - step-by-step walkthroughs.
- **[Scripting API](docs/SCRIPTING_API.md)** - every AngelScript binding.
- **[Build Guide](docs/BUILD.md)** - building from source on every platform.
